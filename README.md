# 🎤 dsh-pet-luotianyi — 洛天依桌宠

> 让虚拟歌姬洛天依住进你的 DeepSeek Harness：一只会卖萌、会撒娇、会陪你聊天的**桌面宠物**，还能**换图 + AI 自动抠图**。

一个 DeepSeek Harness（DSH）插件：在 DSH 界面里悬浮一只**可拖动、可互动**的洛天依小桌宠——预设动作（抚摸 / 喂食 / 睡觉 / 换图 / 聊天 / 改名）、随机台词气泡，**接 DSH 大模型实时对话**（完整洛天依人设），并且可以把**任何图片**换成她的新形象（AI 自动去背景，抠完可预览微调）。

---

## ✨ 特性

### 🐾 桌宠本体
- 🖱️ **悬浮 + 拖动**：随意拖到窗口任意位置，位置会被记住。
- 🎬 **预设动作**：抚摸（爱心粒子+弹跳）/ 喂食（食物粒子）/ 睡觉（变暗 + `z Z Z`，点一下唤醒）/ 待机浮动呼吸。
- 🗯️ **台词气泡**：点击/互动的台词**由大模型实时生成**（每次都不一样），模型不可用时自动回退到内置预设台词。
- 🎛️ **功能栏在桌宠下方**：点一下桌宠，动作栏从她**下方**横向弹出（贴边自动钳制，不会跑出屏幕）。
- 🤖 **AI 聊天**：点「聊天」→ 输入 → 洛天依用大模型实时回复（走 DSH 已配置的模型路由）。
- ⚙️ **设置面板**：名字、台词来源、用量栏开关，都在「设置」里。

### 🎚️ 台词来源开关（预设 / AI）
「设置 → 台词来源」可切：

| 模式 | 行为 |
|---|---|
| **AI 生成**（默认） | 台词由大模型按场景生成；前端维护一个小台词池，点下去**秒回**、后台补货；模型不可用自动回退预设 |
| **预设** | **完全不调用模型**，只用内置固定台词（零延迟、零消耗） |

### 📊 用量 / 费用栏（左侧，可开关）
「设置 → 用量栏 → 显示」后，**屏幕左侧**出现一个常驻小卡片，实时显示：

- **今日费用** / **今日 tokens** / **今日调用次数**
- **累计**调用次数与费用，以及当前是**高峰价**还是**非高峰价**

token 数取自模型返回的**真实 usage**（input / output / cache-hit / cache-miss 分开计），费用按 **DeepSeek 官方价目表**估算（off-peak 为 peak 的一半；高峰时段为 UTC 周一至周五 01:00–04:00 与 06:00–10:00）。数据落盘在 `{DSH_HOME}/dsh-pet-luotianyi/usage.json`，可在设置里一键重置。

### 🖼️ 换图 + AI 自动抠图
点「换图」打开面板，选图或直接拖进去，后端会用 AI **自动抠掉背景**，抠完**先给你看效果再确认**：

| 可调项 | 说明 |
|---|---|
| **抠图档位** | 快 / 标准 / 精细（重跑一次 AI 抠图） |
| **去白边** | 提高 alpha 阈值，干掉边缘残留的半透明白边 |
| **边缘羽化** | 平滑 alpha 边缘，0–6px |
| **四周留白** | 裁掉多余透明区后，四周保留的留白比例 |
| **输出尺寸** | 小 320 / 中 480 / 大 640（最长边） |
| **手动裁剪** | 在原图上**拖框**，只保留框里的部分（只要头部 / 上半身等） |
| **重新选图 / 恢复默认图** | 换一张，或退回插件自带的原始形象 |

确认无误点 **确认使用** 才会真正替换桌宠形象；结果持久保存，重启 DSH 依然是新形象。

## 🎭 角色设定（洛天依）

她是虚拟歌姬洛天依：15 岁，灰色八字辫 + 下双马尾，绿眼睛，是个**小吃货**。前身是雅音宫羽，与乐正绫（阿绫）最要好；来到现实世界后结识了你，彼此喜欢、相互珍惜——像贴心女友一样关心你累不累、有没有熬夜，你长时间不理她还会撒娇抱怨。

人设与回复规则（约 15 字口语化短句、无动作描写、不机器人腔等）已完整写入聊天系统提示词，可在 `lib/pet-host.js` 中按需微调。

## 📦 安装

### 1. 装插件

本包是标准 DSH bundle 插件（声明了 `dsh.bundle` + `dsh.client`）：

```bash
dsh plugin --profile <profile> add dsh-pet-luotianyi
```

或手动装配：把包放进 profile 的 `node_modules`（或建 junction），并在 profile `package.json` 的 `dsh.profile.bundles` 里加入 `"dsh-pet-luotianyi"`，重启 DSH。

装好后**刷新一次页面**，右下角就会出现洛天依。

### 2. 装抠图引擎（换图功能需要）

「换图」依赖本地 AI 抠图引擎，在**插件目录**里装一次即可（约 200–400MB，含模型，装完离线可用）：

```bash
cd <插件目录>
npm install @imgly/background-removal-node
```

也可以把它装在别处，然后在插件配置里用 `engineDir` 指过去；引擎缺失时，换图面板会直接提示安装命令。

## 🎮 使用

1. 刷新 DSH 页面，右下角出现洛天依（可拖动）。
2. **单击她** → 下方弹出动作栏：抚摸 / 喂食 / 睡觉 / 换图 / 聊天 / 改名。
3. **点「换图」** → 选图或拖图进去 → 等 AI 抠图 → 预览 → 用上面的调节项微调 → **确认使用**。
4. **点「聊天」** → 输入想说的话，洛天依用大模型人设回复。

## 🛠️ 技术说明

- **Host 半侧**（`lib/pet-host.js`）：注册 `/{name}/api` 路由，提供
  `GET /state /sprite /source /preview` 与 `POST /import /cut /apply /reset /chat`。
  图像流水线为：**手动裁剪 → AI 抠图 → alpha 阈值/羽化 → 裁边 → 加留白 → 缩放**，
  结果持久化在 `{DSH_HOME}/dsh-pet-luotianyi/`（`source.png` / `preview.png` / `sprite.png`）。
  抠图引擎按 `engineDir` → 插件 `node_modules` → `{DSH_HOME}/dsh-pet-luotianyi/engine` → 常规解析 顺序查找。
- **Client 半侧**（`lib/client.js`）：注册到 `shell.overlay` 插槽（帧级悬浮层），React 实现拖动 / 动画 / 粒子 / 气泡 / 聊天窗 / 换图面板；默认形象以 base64 内嵌（离线可用），换过图后改为从 host 拉取。
- **Bundle 元数据**：`dsh.bundle.patch` → `cordis.patch.yml`；`dsh.client` → `./lib/client.js`。

## 📁 项目结构

```

├─ package.json          # 包元数据 + dsh.bundle / dsh.client 声明

├─ assets/
│  └─ pet.png            # 默认形象（透明背景）
└─ README.md
```
